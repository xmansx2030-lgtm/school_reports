# Tawtheeq UI Update — الإدارة والصيانة

## Updated

- من إدارة المدارس ودليل المدارس وملخص المدرسة: زر POST «إدارة وصيانة» يفتح لوحة المدرسة التشغيلية.
- من المشتركين الأفراد وتفاصيل الحساب: زر «إدارة وصيانة» يفتح مساحة صاحب الحساب مباشرة.
- شريط موحّد يوضح المدرسة أو المعلم، اسم الأدمن، وقت انتهاء الجلسة، أدوات التهيئة، وإنهاء الصيانة.
- نموذج لتهيئة الاشتراك الفردي يدير الباقة والتفعيل وتاريخ الانتهاء، مع تسجيل التعديل الإداري وحفظ حالة المدفوعات الفعلية.
- سجل صيانة بالعربية للدخول والتبديل والخروج والانتهاء، وتسجيل أعمال الصيانة باسم الأدمن.

## UX Improvements

1. افتح «إدارة المدارس» أو «المشتركون الأفراد» من لوحة الأدمن.
2. اضغط «إدارة وصيانة» بجوار المساحة المطلوبة.
3. افتح «أدوات الإدارة والتهيئة» للتنقل إلى الإعدادات والحسابات والتقارير والملفات.
4. اختر «إنهاء الصيانة والعودة للأدمن» عند الانتهاء.

الصيانة متاحة لمالك المنصة `is_superuser` فقط. مدتها ساعة، ويُعاد التحقق من صلاحية المالك في كل طلب. الدخول لا يغيّر كلمة مرور المستفيد أو وقت آخر دخوله أو جلسته الحالية. إعادة تعيين كلمة المرور إجراء مستقل وصريح في حساب المعلم.

تسمح الصيانة بالعمل على مدرسة متوقفة أو مساحة شخصية متوقفة/مكتملة الحدود، دون تفعيل الاشتراك تلقائيًا. تبقى قواعد السنوات المؤرشفة وربط الشواهد والتحقق من الملفات ودورات العمل قائمة. التفعيل اليدوي للاشتراك يستخدم شاشة تهيئة منفصلة ويسجل باسم الأدمن.

الصفحة القديمة في نافذة أخرى تُرفض عند الحفظ إذا تبدلت مساحة الصيانة أو انتهت الجلسة. يظهر تفسير عربي للمستخدم وتُرجع طلبات AJAX خطأ JSON بالحالة 409.

## Design System

إعادة استخدام `.twq-btn` و`.twq-page` و`.twq-section` و`.twq-empty` مع رموز `--twq-*`، وهوية توثيق الخضراء والذهبية. لا توجد تبعية جديدة أو تعديلات على نظام الثيم.

## Responsive

PASS: فحص مساحة المعلم ولوحة المدرسة عند 375 و768 و1024 و1280 و1440 بكسل، في الوضعين الفاتح والداكن. لم يظهر تجاوز أفقي في الصفحة أو شريط الصيانة. الأدوات عمودان على الهاتف، وزر الخروج بعرض متاح لا يقل ارتفاعه عن 44 بكسل.

## RTL

PASS: اتجاه عربي RTL، خصائص CSS منطقية، وعزل الاسم والوقت باستخدام `bdi`.

## Accessibility

PASS: فتح أدوات الصيانة وإغلاقها بـ Enter وSpace، وظهور التركيز بلوحة المفاتيح. استخدام عناصر `aside` و`nav` و`details/summary` وأزرار POST ومسميات واضحة. لم يُنفّذ تدقيق قارئ شاشة شامل أو شهادة WCAG.

## Components

Reused: أزرار وحقول وأقسام وحالات فراغ تصميم توثيق، نماذج إعدادات المدرسة والحساب الشخصي، وسجل `AuditLog` المحصّن.
