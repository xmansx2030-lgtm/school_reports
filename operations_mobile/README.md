# مركز العمليات - Flutter

تطبيق Android مخصص لمشرف النظام لمتابعة `school-reports-prod` والمشاريع المستضافة عليه.

تفاصيل إدارة Hetzner وقراءة السجلات وتجهيز مسار الطوارئ في [دليل إدارة الخادم](../docs/OPERATIONS_SERVER_MANAGEMENT_AR.md).

## المتابعة والإجراءات في 1.1.0

- جرد المشاريع ديناميكي من الخادم، ويشمل المشاريع الخمسة المسجلة دون تثبيت عددها في التطبيق.
- تحليلات الخادم وكل مشروع لفترات ساعة و24 ساعة و48 ساعة و7 أيام، مع متوسطات وذروات الموارد، نجاح فحوص الوصول، زمن الاستجابة، مقارنة المشاريع، تغطية القياسات ووقت آخر عينة. القيم غير المتاحة تظهر فارغة ولا تتحول إلى صفر.
- تفاصيل موارد المضيف والحاويات، وتشخيص المشروع، وسجل إجراءات قابل للتصفية والتصفح. تتبع شاشة الإجراء الطلب نفسه حتى النتيجة أو انتهاء فترة المتابعة؛ التحديث لا يعيد تنفيذ الإجراء.
- قراءة سجلات الخدمات حتى 7 أيام ضمن حد 1000 سطر للصفحة من حاويات الخدمة مجتمعة، مع صفحات أقدم تحافظ على الحد الزمني الأصلي، بحث، تصفية أخطاء وتحذيرات، ونسخ الأسطر المعروضة. تظهر حدود الاقتطاع بوضوح، وقد تكون مدة الاحتفاظ الفعلية بسجلات Docker أقصر من الفترة المطلوبة.
- تحديث يدوي يحافظ على آخر بيانات ناجحة والفترة المختارة وموضع القراءة. أزيل التحديث الدوري العام؛ تظل متابعة نتيجة الإجراء المطلوب فقط تلقائية أثناء فتح شاشته.
- يعرض زر النسخ وصف المسار المعتمد لكل مشروع من الخادم؛ لا يفترض أن كل مشروع يملك نوع النسخة الاحتياطية نفسه.

الواجهات المضافة: `servers/{id}/analytics/?window=48h` و`projects/{id}/analytics/?window=48h` و`projects/{id}/actions/?limit=30`. تتطلب نفس جلسة `Ops-Token` وصلاحيات الخادم الحالية.

## التشغيل المحلي

```powershell
flutter run --dart-define=OPS_API_BASE_URL=http://10.0.2.2:8000/api/operations/v1
```

يستخدم المحاكي `10.0.2.2` للوصول إلى خادم Django على جهاز التطوير. في نسخة الإنتاج، القيمة الافتراضية هي:

`https://tawtheeq-ksa.com/api/operations/v1`

## تفعيل تنبيهات Firebase

أنشئ تطبيق Android في Firebase بالمعرف `com.tawtheeq.tawtheeq_operations`، ثم شغّل التطبيق بهذه القيم العامة:

```powershell
flutter run `
  --dart-define=FIREBASE_API_KEY=... `
  --dart-define=FIREBASE_APP_ID=... `
  --dart-define=FIREBASE_MESSAGING_SENDER_ID=... `
  --dart-define=FIREBASE_PROJECT_ID=...
```

على الخادم فقط، ضع ملف حساب خدمة Firebase خارج المستودع واضبط:

```text
FCM_PROJECT_ID=your-project-id
GOOGLE_APPLICATION_CREDENTIALS=/run/secrets/firebase-service-account.json
```

لا تضف ملف حساب الخدمة أو مفتاح توقيع Android إلى Git.
